# 자동차 도로 거리 적용과 팀 검증 역할

기본 거리 산정을 직선거리에서 **자동차 도로 이동거리**로 변경했습니다. 초기 충전소 B 자동 선택은 좌표상 근접 기준이며, 도로 경로는 선택한 A/B 쌍에 대해서만 조회합니다. 충전소 A/B를 선택하면 A→B와 B→A를 각각 조회합니다. 일방통행·진입 방향에 따라 다를 수 있습니다.

## 거리와 한계

- 경로: [FOSSGIS OSRM car](https://routing.openstreetmap.de/about.html), 지도: [© OpenStreetMap contributors](https://www.openstreetmap.org/copyright). [지도 오류 수정](https://www.openstreetmap.org/).
- [OSRM Table API](https://project-osrm.org/docs/v26.6.1/http#table-service)의 최단시간 경로 거리를 m에서 km로 변환합니다. 최단거리 경로와 같다는 보장은 없습니다.
- 충전소 좌표를 200m 이내 도로 연결점에 붙여 계산합니다. 표시하는 연결점 오차를 확인하세요. 실제 출입구·사유지 통행·공사·실시간 교통을 보장하는 GPS 실측값이 아닌 **도로망 기반 추정값**입니다.
- 서비스에는 공개 충전소 좌표만 전송하며 개인 GPS는 사용하지 않습니다. 공개 서비스 정책에 맞춰 호출을 직렬 처리하고 최소 1초 간격을 유지합니다. 같은 좌표의 결과는 페이지 메모리에서 30분 캐시하며 ‘도로 거리 다시 조회’로 갱신합니다. 반복 실험마다 경로를 재조회하지 않습니다.
- 조회 실패·경로 단절·도로 연결점 누락 시 실행을 차단하고 재조회 또는 수동 입력을 안내합니다. 직선거리로 자동 대체하지 않습니다. 수동 입력은 양방향 동일 거리의 사용자 가정으로 표시합니다.
- 수동/v1 수요는 원래 A를 선택한 차량으로 두므로 A 추가거리는 0, B로 변경하면 A→B 거리입니다. v2는 원래 A/B 선택지를 보존하고, 변경한 방향에 맞는 A→B 또는 B→A 거리를 적용합니다.
- **실제 추가 우회거리는 여전히 가정이 있습니다.** 차량 출발지·최종 목적지를 모르므로 두 충전소 사이의 거리를 우회거리의 대리값으로 씁니다. 실제 주행경로 전체의 우회거리를 계산한 것이 아닙니다.
- 경로 이동시간은 참고로 표시하지만 도착 시각·대기 계산에 더하지 않습니다. 이동 부담은 기존의 α×거리로 반영합니다. 문헌 후보의 30km/h 환산 가정도 자동 재보정하지 않습니다.
- 거리 민감도 분석의 변경 수준은 조회 거리 대신 사용자가 정한 양방향 동일 거리 가정으로 취급합니다. 기준 수준은 원래 양방향 도로 거리를 보존합니다.
- 일반 결과·계수 비교 HTML/CSV의 입력 근거에 조회 시각·출처·URL·양방향 거리와 연결점 오차를 보관합니다.

## 아직 확정되지 않은 값

문헌 환산 후보 s=1, α=950원/km, β=360원/분, τ=7200원은 검증 전 국외 문헌 이전 추정입니다. 제주 충전량 역시 충북 실측이 아닌 외부 자료 이전값입니다. AI 출력, 도로 거리 추정, 행동·점유시간 가정, 요금 정책을 구분해야 합니다. 정책에 유리한 결과가 나온다는 이유로 값을 확정하지 않습니다.

## 팀원 1: 수요·충전 기록과 초기 상태 검증

**목표:** 시뮬레이션에 들어가는 수요와 점유시간이 실제 기록과 맞는지 확인합니다.

1. 충전소 ID·급속/완속·시각을 맞춰 15분별 실제 충전 시작 건수를 만들고 AI 예측과 비교합니다. 충전 시작 건수와 대기·포기를 포함한 도착 수의 차이를 명시합니다.
2. 완료된 세션의 시작·종료로 점유시간 분포를 정리합니다. 진행 중·누락·중복 기록은 따로 표시하고, 시작 시 충전 중인 차량의 경과시간과 잔여시간 추정 방법을 검토합니다.
3. 제주 충전량의 이전 가능성과 대표 출력의 한계를 확인합니다. kWh나 전력 계측이 없으면 점유시간만으로 에너지를 확정하지 않습니다.
4. 실험할 충전소 쌍의 출입구·양방향 도로 거리를 지도에서 표본 확인합니다. 스냅 지점 오차와 사유지·진입 제한을 기록합니다.

**산출물:** 충전소·15분별 예측/관측 비교표, 급속/완속 점유시간 요약, 초기 잔여시간 후보, 수요가 충분한 실험 쌍과 시간대 목록. 각 표에 자료 기간·유효 표본 수·누락률을 기재합니다.

## 팀원 2: 행동계수 근거와 정책 비교 실험

**목표:** 운전자 선택 가정이 바뀌어도 정책 결론이 유지되는지 확인합니다.

1. [문헌 환산 후보](behavior-presets.md)의 가격 단위·거리/시간 단위·표본·환산식을 검토하고, 전비·환산값·이동속도·소득 조건 중 무엇이 가정인지 표로 정리합니다.
2. 요금·추가 이동·대기시간을 함께 제시한 선택 설문 또는 실제 선택 기록을 확보할 수 있으면 α·β·τ 보정을 준비합니다. 네 계수의 척도 문제를 고려해 가격 민감도 1을 기준으로 둡니다.
3. 팀원 1이 확정한 동일 수요·초기 상태로 기존값과 문헌 후보를 비교하고, 한 항목씩 민감도 분석을 실행합니다. 정책 할인·할증·여유 기준은 행동계수와 별도로 비교합니다.
4. B 선택 비율, 평균 대기, 같은 시각 A+B 합산 피크·저감률, 이용자 요금·추가 이동·단순 매출을 함께 평가합니다. 신규 수요가 적은 사례와 정책 순위가 바뀌는 사례를 별도 기록합니다.

**산출물:** 계수별 값·단위·출처·환산 가정·비교 범위 표, 조건을 고정한 비교 HTML/CSV, ‘모든 조건에서 유지된 결론’과 ‘가정에 따라 달라진 결론’을 구분한 팀 보고서.

두 팀원은 같은 자료 시점·충전소 ID·급속/완속·예측 구간·시드·반복 횟수·거리 조회값을 공유합니다. 표본이 적으면 후보 범위와 한계를 보고하며 검증된 확정값으로 표현하지 않습니다.
