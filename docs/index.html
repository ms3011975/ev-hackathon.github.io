요금 정책

표는 공공 요금 기준 예시입니다. 지도와 목록의 거점 단가는 그 충전소 운영사의 실제 회원가로 계산합니다.

거점 목록

요금 계산 방식

동적 단가 = 운영사 실제 회원가(출력 구간별) × 혼잡 배수 × 시간대 배수
  1. 충전기 상태로 대기, 충전 중, 고장을 셉니다.
  2. 대기율은 대기 ÷ (대기 + 충전 중)입니다. 고장 난 충전기는 계산에서 뺍니다.
  3. 급속과 완속을 따로 판정합니다. 대기율이 기준 이상이면 여유(할인), 대기가 한 대라도 있으면 보통, 전부 충전 중이면 혼잡(할증)입니다.
  4. 혼잡하거나 고장 난 거점마다 반경 안에서 가장 가까운, 같은 속도가 여유인 거점을 안내합니다.

기본 단가는 각 충전소 운영사의 실제 회원가입니다. 무공해차 통합누리집(ev.or.kr) 사업자별 요금 매트릭스에서 102개 운영사의 출력 구간별(완속 30kW 미만, 중속 30~49kW, 급속 50~99kW, 급속 100~199kW, 초급속 200kW 이상) 회원가·비회원가를 받아, 충전기의 운영기관과 출력에 맞춰 붙였습니다. 운영사가 그 출력 구간 요금을 올리지 않았으면 같은 운영사의 가장 가까운 구간을, 운영사 요금이 아예 없으면 공공 요금(기후에너지환경부, 2026.8.1 시행: 295~393.1원)을 씁니다. 충북 충전기의 약 92%가 운영사 실제 요금으로 계산됩니다.

충전기 데이터: 한국환경공단 전기자동차 충전소 정보 API(공공데이터포털). 시·군 경계: 통계청 2018 시군구 경계. 충전소 이름, 위치, 상태는 실제 API 값이고, 기본 요금은 무공해차 통합누리집에 등재된 운영사 회원가입니다. 혼잡 배수를 곱한 동적 단가는 정책 시뮬레이션 값이며 실제 청구 요금이 아닙니다.
