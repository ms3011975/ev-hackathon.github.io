# AI 수요 예측 출력과 충전 부하 분석 리포트

최신 기준: **2026-11-05 팀 채택 자료 반영**. [팀 결정 목록과 역할](simulation-parameters.md#팀에서-정할-사항)을 먼저 확인하세요.

이번 개발 범위는 **AI 기준 수요 예측 → 규칙 기반 요금 정책 → 수요 분산 시뮬레이션 → 충전 부하 분석 리포트**입니다. 강화학습, LLM 관제, 실제 배전망 해석은 후속 범위로 둡니다.

공유 사이트: https://ms3011975.github.io/ev-hackathon.github.io/#simulation

## 전체 연구 흐름과 결과

**연구 질문.** 같은 신규 수요를 두고 여유 충전소 B를 할인하면, 일부 운전자가 B로 이동해 혼잡 충전소 A의 충전량과 개별 피크가 줄어드는가?

1. **입력 구성:** 공공데이터에서 시작 시점의 충전기 상태를 가져오고, 완료 기록으로 신규 충전시간과 초기 차량 잔여시간을 추정합니다. 건당 충전량은 제주 자료 기반 급속 14.82 / 완속 16.24kWh, 이동거리는 A↔B 도로 경로, 운전자 행동은 급속·완속별 팀 기준을 사용합니다.
2. **기준 수요 예측:** 외부 AI v2가 제공하는 충전소별 15분 이용률과 기대 충전 시작 건수를 사용합니다. 이용률은 요금 판정에, 기대 건수는 모의 신규 도착 생성에 쓰입니다. 예측 구간의 수요를 수동으로 늘리지 않았습니다.
3. **정책 모의실험:** 같은 초기 상태와 신규 도착·선택 난수를 공유해 고정요금, 할인·할증, 할인 전용을 비교합니다. 각 운전자의 선택은 충전비·이동거리·예상 대기에 따라 달라지며, 선택 후 충전기에 배정해 실제 모의 대기와 충전 시점을 계산합니다.
4. **성과 평가.** A에서 공급한 충전량(kWh)과 A의 개별 피크(kW)를 핵심 지표로 둡니다. B 선택 비중으로 수요 이동을 확인하고, B 개별 피크와 A+B 동시 합산 피크로 수요를 받은 쪽과 두 지점 전체의 변화를 확인합니다. 피크는 반복마다 15분 평균 등가 부하의 최댓값을 구한 뒤 평균합니다. 충전비·매출·대기와 정책값·행동계수 민감도도 함께 봅니다.

### 요금 정책 비교

[저장 실험 조건](#정책-민감도-실행-사례): 2026-11-05 11:15 KST 예측과 같은 시각 초기 상태, 100회 반복·시드 42, 팀 행동계수, 할인 20%·할증 15%·여유 빈 비율 50%. 충주 급속은 금릉주차장(A)과 칠금동공영주차장(B), 청주 완속은 테라스퀘어빌딩(A)과 복대신영지웰시티1차몰(B)입니다. 남은 약 99분의 신규 기대 건수는 각각 4.116건과 1.661건입니다.

할인 후 **A 충전량은 급속 1.04kWh/회, 완속 0.65kWh/회 줄었고, A 개별 피크는 각각 0.72%, 1.37% 낮아졌습니다.** A 충전량은 초기 차량과 신규 차량이 모두 완료될 때까지 A에서 공급한 모의 에너지의 반복 평균입니다. B 선택 비중은 급속 1.67%p, 완속 2.38%p 높아졌습니다.

보조 지표인 A+B 합산 피크는 급속 0.79%, 완속 0.13% 높아졌습니다. 합산 피크는 접속 관계와 무관하게 같은 15분 구간의 두 부하를 더해 계산합니다. 충전 장소가 바뀌면서 A의 부하는 줄었지만, 두 곳의 충전이 시간상 겹치는 정도는 정책에 따라 달라질 수 있습니다. 예측 이용률 100% 구간이 없어 할증 적용은 0건이었고, 이 때문에 두 할인 정책의 결과가 같았습니다.

### 행동계수와 정책값에 따른 변화

같은 예측에서 할인·할증 정책의 행동계수만 기존 예시에서 팀 기준으로 바꾸면, 급속 B 선택은 76.43% → 67.14%, A+B 피크는 80.477 → 77.232kW였습니다. 완속은 66.07% → 57.14%, 27.980 → 27.577kW였습니다. **각 행동계수 안에서** 고정요금과 비교한 B 선택 증가폭도 급속 +5.95%p → +1.67%p, 완속 +9.52%p → +2.38%p로 줄었습니다. 이는 운전자 선택 가정에 따라 효과의 크기가 달라진다는 뜻입니다. 행동계수 간 피크 차이는 요금 정책의 저감 효과로 해석하지 않습니다.

[할인율 10·20·30% 비교](#정책-민감도-실행-사례)에서도 할인율이 높을수록 B 선택 비중은 늘었지만, 합산 피크가 고정요금보다 낮은 수준은 없었습니다. 사례별 신규 수요가 적고 A/B 충전기 수가 다르며 충전량·잔여시간·행동계수에 추정과 가정이 포함됩니다. 결과는 두 저장 사례의 모의실험으로 보고하고 실제 지역 전체 효과나 최적 할인율로 일반화하지 않습니다.

## 후속 확장: 배전망 연계

현재 자료로 확인한 범위는 A와 B의 모의 충전 부하입니다. 실제 설비의 피크 변화는 **접속 관계와 같은 시간대의 기존 부하**에 따라 달라집니다. 아래는 실제 A/B의 연결 정보를 확보한 뒤 적용할 두 가지 해석입니다.

| 접속 조건 | 결과를 해석하는 방법 |
|---|---|
| A와 B가 같은 변압기나 선로를 공유 | 해당 설비에 걸리는 A와 B의 동시 부하를 기존 부하에 함께 합칩니다. B에서 늘어난 부하가 A에서 줄어든 부하를 상쇄할 수 있습니다. A+B 합산 피크는 두 충전소 몫의 변화를 보여주며, 설비 전체 피크의 방향은 기존 부하를 더한 시계열에서 판단합니다. |
| A와 B가 서로 다른 변압기에 접속 | A측과 B측의 기존 부하에 각 충전소 부하를 따로 합칩니다. A측 피크가 완화될 가능성과 B측 부담이 커질 가능성을 각각 평가합니다. 두 변압기가 상위 선로를 공유하면 그 선로의 동시 부하도 별도로 확인합니다. |

1. **연결 확인:** 충전소 ID를 실제 접속 지점·변압기·배전선로에 매핑하고 설비 정격과 시간대별 기존 부하를 확보합니다. 같은 변압기에 물린 곳은 함께 평가하고, 서로 다르면 각각 평가하면서 공통 상위 선로도 확인합니다.
2. **부하 합성:** 정책별 A/B의 15분 부하를 실제 시각 기준으로 맞춰 각 접속 지점의 기존 부하에 합성합니다. 기존 계측에 실험 대상 EV 충전 부하가 포함돼 있으면 해당 성분을 분리한 뒤 모의 부하로 대체해 중복을 피합니다. 같은 기간·기존 부하에서 고정요금과 비교합니다.
3. **설비 영향 평가:** 설비별 피크·여유 용량·정격 초과 시간을 비교합니다. 변압기 정격이 kVA라면 역률이나 무효전력 자료로 피상전력을 구해 같은 단위로 비교합니다. 계통 구성·선로 임피던스와 전압 자료까지 확보하면 전력 흐름과 저전압 발생 여부를 평가합니다. [NLR EVI-DiST](https://www.nlr.gov/transportation/electric-vehicle-infrastructure-distribution-system-integration-tool)는 변압기·선로·전압 영향 평가의 방법 참고 사례입니다.

**요일별 패턴 고도화**는 별도로 예측 단계에서 수행합니다. 기록이 더 쌓이면 평일·주말·공휴일 수요 차이를 학습에 반영하고, 학습에 사용하지 않은 날짜에서 기존 방식과 예측 오차를 비교합니다. 이후 같은 요금 정책을 다시 실행해 시점이 달라져도 결과 방향이 유지되는지 확인할 수 있습니다. 배전망 연계는 이 예측의 정확도 검증과 별개로, 정책별 충전 부하가 연결 설비에 미치는 영향을 평가합니다.

## 발표 구성과 멘트

1. **개발 배경.** “충북 충전소에서 수요가 특정 거점과 시간대에 몰리면 대기가 길어지고, 같은 설비에서 여러 부하가 겹칠 경우 배전망의 피크 부담도 커질 수 있습니다. 여기서 혼잡한 충전소의 부담을 줄일 수 있는지 연구를 시작했습니다.”
2. **구현 방향.** “충전기 상태와 예측 이용률로 여유·혼잡을 판정합니다. 여유 거점 할인과 혼잡 거점 할증으로 운전자의 선택이 바뀌는지, 그 결과 A의 충전량과 개별 피크가 줄어드는지 비교합니다.”
3. **구현 방법.** “공공데이터에서 충전기 상태와 위치를 수집하고, 관제 플랫폼에서 혼잡도·요금·대체 거점을 표시합니다. AI 모델의 15분 단위 이용률은 요금 판정에, 신규 충전 시작 건수는 차량 도착 생성에 사용합니다. 급속과 완속 각각에서 같은 예측 수요와 초기 상태를 두고 세 가지 요금 정책을 100회 반복해 비교했습니다.”
4. **결과.** 다음 순서로 예측 검증과 정책 효과를 발표합니다.
   - **예측 정확도.** “저장본의 충북 급속 1시간 신규 건수 검증에서 RMSE는 0.508건이었습니다. 공식 단독의 0.515건보다 낮았지만, 시간대 균일 기준의 0.468건보다는 높았습니다. 완속은 이 저장본에서 검증 기록이 부족했습니다.” [검증 조건과 수치](#ai-신규-충전-건수-검증)
   - **수요 분산과 충전소별 부하.** “할인 20%에서 B 선택 비중은 급속 1.67%p, 완속 2.38%p 높아졌습니다. A 충전량은 급속 1.04kWh, 완속 0.65kWh 줄었고, A 개별 피크는 각각 0.72%, 1.37% 낮아졌습니다.” [세 정책 비교표](#요금-정책-비교)
   - **보조 지표와 접속 조건.** “A+B 합산 피크는 급속 0.79%, 완속 0.13% 높아졌습니다. 두 곳이 같은 설비를 쓰면 B에서 늘어난 부하가 A의 저감을 상쇄할 수 있습니다. 서로 다른 변압기에 연결되면 A측과 B측을 따로 보고, 공통 상위 선로가 있다면 그 선로도 확인해야 합니다.”
5. **결론.** “두 모의 사례에서 할인은 수요 일부를 B로 옮겨 A의 충전량과 개별 피크를 낮췄습니다. 예측 이용률 100% 구간이 없어 할증은 적용되지 않았습니다. 결과의 적용 범위는 두 충전소 쌍의 모의 충전 부하입니다.”
6. **제언.** “평일·주말 등 다른 날짜와 여러 충전소 쌍에서 예측과 정책 결과를 검증하겠습니다. 배전망은 A·B의 실제 접속 설비를 확인하고, 같은 시간대 기존 부하에 충전 부하를 합쳐 변압기와 선로별 피크 및 정격 초과 시간을 비교하는 후속 과제로 제안합니다.” [배전망 연계 방법](#후속-확장-배전망-연계)

## 실제 제공 모델 연결

**AI 수요 모델 연결**을 누르면 실제 충전소 상태와 [15분 구간 수요 모델 v2](https://ev-hackathon.github.io/data/forecast_v2.json)를 읽습니다. 구간별 기대 건수와 가정값을 확인한 뒤 실행하세요. 기본으로 실행마다 최신 URL과 초기 상태를 다시 읽습니다. 파일·붙여넣기 입력은 이 옵션을 해제하며 최대 10MB를 지원합니다.

[1시간 후 이용률 v1](https://ev-hackathon.github.io/data/forecast.json)은 요금만 변경하고 수요는 수동 설정을 사용합니다. [모델 제공 명세](https://github.com/ev-hackathon/ev-hackathon.github.io/blob/main/docs/forecast-io.md)에 따르면 v2 이용률은 구간 중앙 시점의 보간 예측이고 신규 건수는 충전 중 대수·충전시간·시간대 모양에 기반한 추정입니다. 시뮬레이션은 제공 이용률을 각 구간 동안 고정해 사용합니다.

- 실험의 0분은 실행 시점입니다. 이미 지난 예측 구간은 제외하고 처음 일부 구간의 기대 건수는 남은 시간 비율로 조정합니다. 구간 내 시작이 균등하다는 추가 가정입니다.
- 초기 상태는 45분 이내 수집값을 요구하며 수집 이후 실행까지 상태가 유지됐다고 가정합니다. 생성 후 90분이 지난 모델, 종료된 구간, A/B 누락·중복·불연속·잘못된 비율/건수는 차단합니다.
- A/B별 기대 충전 시작 건수를 평균으로 하는 독립 포아송 차량을 생성합니다. 같은 차량·도착·원래 선택지·초기 잔여시간을 세 정책이 공유합니다. 원래 선택지에서는 추가 거리 0, 다른 곳으로 바꿀 때만 A↔B 추가 거리를 적용합니다.
- 요금은 차량 도착 구간의 이용률로 결정하고 선택한 단가를 충전 종료까지 유지합니다. 요약 표의 단가는 시간가중 평균이며 리포트에 구간별 요금을 별도 기록합니다. 기준 예측을 정책 후 이용률로 강제하지 않습니다. 한 실행 중 모델을 다시 호출해 피드백하는 구조는 아니며 갱신 결과는 다음 실행 때 적용합니다.
- 신규 인원과 생성 기간은 예측에서 정합니다. 민감도 분석에서는 할인율·충전량·행동계수 등 나머지 가정을 비교하며 인원·기간 변경은 수동 모드에서 합니다.
- 건수는 대기·포기 차량을 포함한 실측 도착 수가 아닙니다. kWh는 제주 추정값 또는 직접 입력 가정, 행동계수는 기존/사용자 가정 또는 종류별 팀 채택 문헌 기준입니다. 완속은 여러 연구의 대리값 조합이며 공동 추정·지역 검증 전입니다. v2 제공 평균 시간은 참고로 보존하고, 실제 화면 기본 `sessions`는 별도 조회한 완료 세션 원기록의 경험분포를 적용합니다. 시간에서 kWh를 역산하지 않습니다.

리포트는 기대 인원과 생성 평균·최소·최대·0명 반복 횟수를 표시합니다. 차량당 대기·비용·거리는 모든 반복의 생성 차량을 합쳐 집계하고 대기 SE는 반복을 묶음으로 보는 비율 추정의 표준오차입니다. 신규 차량이 전혀 생성되지 않았다면 대기·비용·선택비율의 0을 정책 효과로 해석하지 않습니다. 초기 차량의 부하는 계속 집계합니다.

HTML·CSV에는 실제 사용한 구간, 시작·수집 시각, 기대 건수, 요금, 생성 통계, 모델 방법·검증·가정값을 남깁니다. 반복의 재현에는 시드뿐 아니라 같은 수집 상태와 **저장한 forecastPlan의 시작 시각·남은 구간**이 필요합니다. 다른 시각에 최신 모델을 다시 읽으면 조건이 달라집니다. p10/p90은 모델의 원래 구간별 참고치이며 이번 버전은 그 분위수를 합산 수요의 신뢰구간으로 사용하지 않습니다.

## 연결이 안 될 때

‘AI 수요 모델 연결’은 원본 공개 JSON을 다시 읽고 검증합니다. 모델 실행·원본 Actions 재시작·예측 유효기간 연장은 하지 않습니다.

| 표시 | 의미와 조치 |
|---|---|
| 불러오는 중 | 예측·상태 조회 중. 인원·기간은 비워 두고 대기 |
| AI 예측 확인 필요 | v2에 쓸 검증된 계획이 없음. 수동으로 숫자를 넣으라는 의미 아님 |
| 추정값 + 자동 인원/기간 | v2 검증 성공. 실제 인원 실측이 아닌 기대 충전 시작 건수 |
| 예측 유효기간 초과 | 생성 시각·현재 시각·경과 분 표시. 원본 생성 후 90분 이내 파일 필요 |
| 초기 상태 45분 초과 | 상태 저장본의 실제 수집 시각 확인. 새로 읽어도 같으면 원본 수집·배포 점검 |
| 남은 구간 1분 미만 | 예측 기간이 끝남. 다음 결과를 받아야 하며 과거 구간은 생성하지 않음 |
| A/B 누락·종류·구간 오류 | 선택 ID·fast/slow·양쪽 동일 15분 구간·중복·누락 확인 |
| 조회 실패 | URL·네트워크·CORS·응답 상태 확인. 이전 예측을 조용히 재사용하지 않음 |

1. ‘요금·수요 기준’이 v2인지 확인하고 **AI 수요 모델 연결**을 누릅니다.
2. 버튼 아래 연결 상태와 **수신한 예측 생성 시각**, 초기 상태 수집 시각을 확인합니다. 실패 시 신규 인원·기간은 비워지고 이전 숫자를 AI 값으로 실행하지 않습니다. 수동 모드로 바꾸면 이전 수동값을 복원합니다.
3. [공개 v2 JSON](https://ev-hackathon.github.io/data/forecast_v2.json)의 `generated_at`과 [상태 JSON](https://ev-hackathon.github.io/data/status.json), 실제 선택 지역의 수집 시각을 대조합니다. 사이트를 새로고침해도 원본 시각이 같다면 브라우저 입력만의 문제가 아닐 수 있습니다.
4. 모델 제공 담당자는 [원본 Actions 실행 목록](https://github.com/ev-hackathon/ev-hackathon.github.io/actions)에서 예약 실행·대기/실패·수집·모델 추론·Pages 배포를 확인합니다. 2026-11-04 19:46(한국 시각) 확인에서는 파일과 최근 실행이 17:15에 머물렀습니다. 당시 관찰이며 예약 중단의 정확한 원인은 확인되지 않았습니다. 오래된 파일을 반환해도 HTTP 200과 마지막 작업 성공만으로 최신 예측은 아닙니다.
5. 최신 자료가 갱신되면 다시 연결합니다. 기다리는 동안 수동 모드로 예시 24명/60분 등의 가정 실험을 할 수 있으나 AI 연결 결과로 보고하지 않습니다. 초기 수집 시각도 명시합니다.

**복구 재확인:** 2026-11-04 23:36(한국 시각)에는 공개 예측·청주시 상태가 23:30으로 갱신되고 원본 최근 배포도 성공했습니다. 최신 상태를 다시 받은 로컬 화면에서 실제 v2의 자동 입력을 확인했습니다. 19:46의 17:15 정체는 당시 진단 사례이며, 이후에는 화면의 최신 생성·수집 시각으로 판단합니다.

만료 검사를 없애거나 JSON 시각만 바꾸지 않습니다. 형식 예시는 실제 모델 검증 자료가 아니며 `example_only=true`는 실행 차단합니다. 연결 데이터는 제공 서비스가 관리하며 개인 사이트 코드 배포와 별개로 갱신됩니다.

## 1 현재 지원하는 모델 출력

지원하는 버전 1(v1)은 미래 한 시점의 이용률을 받아 정책 요금에만 반영합니다. 초기 충전기 상태는 선택한 수집 상태를 유지하고, 운전자 수·충전량·시간은 화면 설정을 사용합니다.

아래는 **형식 설명용 가상 수치**입니다. 실제 모델 결과가 아니며 실행용 파일이 아닙니다.

```json
{
  "schema_version": 1,
  "example_only": true,
  "model_name": "FORMAT_EXAMPLE_NOT_A_MODEL",
  "generated_at": "2026-11-03T14:00:00+09:00",
  "target_time": "2026-11-03T15:00:00+09:00",
  "predictions": [
    {"station_id": "DEMO-A", "speed": "fast", "utilization": 0.8},
    {"station_id": "DEMO-B", "speed": "fast", "utilization": 0.2}
  ]
}
```

| 출력 | 의미와 적용 |
|---|---|
| station_id | 공공데이터 충전소 ID와 일치. 예시의 DEMO ID는 실제 충전소가 아님 |
| speed | fast 급속 또는 slow 완속. 화면 선택과 일치 |
| utilization | 가동 가능한 충전기 중 충전 중인 비율 0~1. 현 계약은 대상 시점의 비율 |
| generated_at | 모델이 결과를 만든 시각. 시간대 포함 |
| target_time | 미래 예측 대상 시각. 생성 시각 이후이면서 실행 시점보다 미래 |
| model_name | 모델 이름과 버전 |
| example_only | true이면 형식 설명용으로 분류하여 실행 차단 |

실제 연결 시에는 실제 ID·모델명·시각·예측값을 넣고 example_only를 제거하거나 false로 설정해야 합니다. 단순히 이 표시를 지워도 예시 숫자가 실제 예측이 되는 것은 아닙니다. 화면에서 현재 선택된 A/B에 맞춘 형식 예시 JSON을 다운로드할 수 있습니다.

현재 여유 판정 기준이 50%이면 이용률 50% 이하는 할인 대상, 50% 초과~100% 미만은 보통, 100%는 혼잡입니다. 80%를 자동으로 혼잡으로 처리하지 않습니다. v1 단가는 실행 중 고정하며 v2는 구간별로 적용합니다.

## 2 현재 연결된 구간별 출력 계약(v2)

다음은 **현재 연결된 버전 2의 형식 예시**입니다. 실제 제공 모델의 구간별 이용률·신규 건수를 자동 적용합니다. 과거 충전 패턴·시간·기상이 입력이라는 이유만으로 kWh나 가격 반응까지 제공되는 것은 아닙니다.

아래 역시 형식 설명용 가상 수치입니다.

```json
{
  "schema_version": 2,
  "example_only": true,
  "model_name": "charging-demand-v0.1",
  "generated_at": "2026-11-03T14:00:00+09:00",
  "simulation_start_at": "2026-11-03T14:00:00+09:00",
  "interval_minutes": 15,
  "baseline": "existing_prices_without_new_policy",
  "demand_measure": "charging_starts",
  "predictions": [
    {
      "station_id": "DEMO-A", "speed": "fast",
      "interval_start": "2026-11-03T14:00:00+09:00",
      "interval_end": "2026-11-03T14:15:00+09:00",
      "utilization_mean": 0.8,
      "expected_new_sessions": 4.2
    },
    {
      "station_id": "DEMO-B", "speed": "fast",
      "interval_start": "2026-11-03T14:00:00+09:00",
      "interval_end": "2026-11-03T14:15:00+09:00",
      "utilization_mean": 0.2,
      "expected_new_sessions": 1.5
    }
  ]
}
```

실제 출력에는 대상 기간의 모든 구간에 대해 A/B 양쪽 결과가 필요합니다. 중복·누락·구간 겹침·충전기 종류 불일치를 검증하고 시간 구간의 정의를 통일해야 합니다.

| 항목 | 시뮬레이션 반영안 | 필요한 자료 |
|---|---|---|
| simulation_start_at | 모델 원래 시작 시각. 실제 실험 0분은 max(실행 시각, 모델 시작)이며 지난 구간 제외 | 45분 이내 관측 상태, 수집 이후 유지 가정 |
| interval_start / end | 차량을 생성하는 15분 등의 시간 구간 | 같은 시간 간격의 이력 |
| utilization_mean | 제공 모델의 구간 중앙 시점 이용률 예측. 해당 구간 동안 고정해 요금 판정 | 이용률 이력 |
| expected_new_sessions | 구간의 평균 신규 건수. 4.2건은 기대값이며 정수 실적이 아님 | 충전 시작 이력 또는 도착 기록 |
| demand_measure | 현재는 charging_starts를 지원. 실제 도착 건수 arrivals는 별도 연결 필요 | 학습 정답의 정의 |
| baseline | 새 정책 도입 전 기준 수요임을 표시 | 학습 기간의 요금 조건 |

충전 시작 건수에는 대기 중이거나 충전을 포기한 차량이 포함되지 않습니다. 도착 인원의 대용으로 쓰면 **충전 시작 건수에서 추정한 도착 수요**라고 표시해야 합니다. 평균 건수에서 정수 차량을 생성하는 방법과 확률분포도 따로 합의해야 합니다.

A/B가 같은 수요 집단의 선택지라는 전제에서 합계 건수로 공통 기준 차량을 만들고 정책별 선택을 다시 계산합니다. 정책 적용 후에도 예측 A/B 건수를 강제하면 분산 효과를 평가하기 어렵습니다. 다른 충전소와의 유출입은 별도로 대상 범위를 정해야 합니다.

### 추가 자료가 있으면 사용할 수 있는 출력

- mean_energy_kwh: 신규 1건당 평균 충전량. 건물·지역 전체 전력 사용량과 구분해야 하며 개별 충전량 이력이 필요합니다.
- duration_minutes의 분포: 실제 충전시간과 점유시간을 구분합니다. 개별 시작·종료 기록이 필요하며 평균뿐 아니라 변동도 활용할 수 있습니다.
- 예측 구간·분위수: 낮음·중간·높음 수요 시나리오에 사용합니다. 계산 방법과 확률 수준을 표시해야 합니다.

mean_energy_kwh와 예측 분위수 시나리오는 현재 자동 적용하지 않습니다. 완료 기록 분포는 이미 `sessions` 모드로 연결했고, v2의 요약 평균을 직접 대입하지 않습니다. [각 설정값의 의미](simulation-parameters.md)도 참고하세요. 가격 민감도·α·β·τ는 이용률 예측만으로 구할 수 없습니다. 할인·할증률은 정책 비교로 정하며 반복 횟수·난수 시드는 실험 설정으로 유지합니다.

## 3 현재 분석 리포트 사용법

1. 비교할 A/B, 수요·행동 가정, 요금 판정 근거를 설정합니다.
2. 실제 화면 시간 기본은 **완료 기록 기반 `sessions`**입니다. 최근 30일·같은 종류·충전소 5건→지역 5건→출력 기반 대체를 사용합니다. `power`(충전량÷대표 출력×60분), `assumed`(20~40분)도 비교할 수 있습니다. [시간 추정 상세](simulation-parameters.md#44-신규-차량-충전시간)를 확인합니다.
3. 시뮬레이션을 실행하면 정책 비교 아래에 **충전 부하 집중 변화 리포트**가 표시됩니다.
4. **분석 리포트 HTML 다운로드**로 단일 파일을 공유합니다. 외부 스크립트나 로그인 없이 열 수 있고 브라우저 인쇄로 PDF를 만들 수 있습니다.
5. **부하 시계열 CSV 다운로드**로 입력 근거·지표·정책별 15분 평균 시계열을 저장합니다.

입력을 변경하면 이전 실행 리포트라고 표시하고, 다시 실행할 때까지 다운로드를 비활성화합니다.

## 4 부하 계산과 비교 지표

신규 차량의 부하는 설정한 충전량을 모의 충전 시작부터 종료까지 일정 전력으로 공급하는 **에너지 보존 등가 모형**입니다.

```text
신규 차량 등가 전력 kW = 충전량 kWh ÷ 충전시간 h
sessions 보정 총시간 T(분) = max(원기록 추출 시간, 60×E/대표kW)
sessions 초기 전력 kW = 60×E/T, 잔여 에너지 kWh = E×R/T
power/assumed 초기 전력 kW = 충전소 대표 출력 kW
15분 평균 부하 kW = 해당 15분 동안 공급한 충전량 kWh ÷ 0.25 h
합산 부하(t) = A 부하(t) + B 부하(t)
피크 저감률 % = (고정요금 평균 피크 - 정책 평균 피크) ÷ 고정요금 평균 피크 × 100
```

20~40분 가정 모드에서는 충전량에 따라 등가 전력이 대표 출력을 넘을 수 있습니다. 해당 경우 화면·HTML에 물리적 해석의 제한을 표시하고 CSV에도 해당 차량 수를 기록합니다. 전력을 잘라내거나 수요를 제거하지 않습니다. 출력 기반 모드에서는 충전시간과 충전량이 일관됩니다.

완료 기록 모드의 초기 잔여 R은 T에 비례하는 길이 가중 표본과 0~T 균등 잔여로 추정합니다. 현재 시작시각은 공개되지 않아 정상상태 가정이며 실측 잔여가 아닙니다. 초기 차량에도 별도 E를 총량으로 가정합니다. 다른 모드는 대표 출력×균등 잔여시간으로 에너지를 추정합니다. `sessions`는 짧은 시간을 최소시간까지 연장해 E를 보존하고 대표 출력 초과를 막으며, 원표본/실행 차량의 연장 수와 원평균·적용 평균을 구분해 기록합니다. 충전곡선, 효율, 출력 공유, 건물의 다른 부하, 변압기·배전선로 제약은 반영하지 않습니다.

| 지표 | 해석 |
|---|---|
| A / B 피크 | 충전소별 최대 15분 평균 부하. 순간 최대전력과 구분 |
| A+B 합산 피크 | 같은 시각의 합산 곡선에서 산출. 각 충전소 최대값의 합이 아님 |
| 피크 저감률 | 양수는 감소, 음수는 증가. 고정요금 기준이 0이면 산정 불가 |
| 피크 및 차이 SE | 반복 난수의 표준오차. 차이 SE는 같은 반복의 정책 차이로 산출 |
| A/B 평균 부하율 차이 | 도착 생성 기간의 평균 부하를 처리 가능 대표 용량으로 나누고 두 비율의 절댓값 차이를 %p로 표시. 작을수록 상대 부하가 가까움 |
| 시간 연장 신규 차량 | `sessions`에서 E·대표 출력의 최소 필요시간까지 늘린 차량 수(반복 평균). 원기록 시간 그대로 적용된 차량과 구분 |
| 기간 이후 충전량 | 도착 생성 기간 이후 공급되는 에너지. 수요의 선행·지연을 확인 |
| 종료 시 미완료 차량 | 도착 생성 종료 시점의 대기 또는 충전 중 신규 차량 |
| 최종 완료 시각 | 초기·신규 차량 모두 충전을 완료하는 데 걸리는 시간 |
| 비용과 대기 | 평균 충전비·추가 거리·대기, 총 할인, 단순 매출 차이 |

표는 **각 반복에서 최대값을 구한 뒤 평균**합니다. 곡선은 반복 평균 시계열이므로 곡선의 최대값과 표는 다를 수 있습니다. 저감률은 평균 피크끼리 계산하며 각 반복의 저감률 평균과 구분합니다. 긴 시계열은 그래프만 최대 240구간으로 묶고 CSV는 원본 15분 값을 유지합니다.

A·B·합산 그래프마다 **회색 실선=고정요금, 녹색 실선=할인·할증, 주황 점선=할인 전용** 범례를 표시합니다. 각 그래프 아래에 축·반복 평균·계단·선 겹침·도착 생성 종료 이후 감소의 의미와 해당 충전소 또는 합산 부하의 해석을 설명합니다. 세로 눈금은 자동 범위로 정격 용량을 뜻하지 않습니다. 이 설명과 범례는 다운로드 HTML에도 포함합니다.

모든 정책이 같은 차량·도착·초기 상태를 공유합니다. 도착 기간 이후에도 전 차량 완료까지 계산해 같은 수요를 비교합니다. 부하 시계열은 공통 종료까지 0으로 채웁니다. 20,000구간을 넘는 극단적인 장기 조건에서는 부하 리포트를 생성하지 않고 이유를 표시합니다.

## 5 보고서에서 전달할 결론

A의 충전량과 개별 피크의 고정요금 대비 변화를 먼저 보고합니다. B 선택 비중은 수요 이동의 근거로, B 피크와 같은 시각의 A+B 합산 피크는 이동을 받은 쪽과 두 지점 전체의 변화를 설명하는 보조 지표로 사용합니다. 모의 결과의 적용 범위와 실제 설비 영향을 검증하는 데 필요한 자료를 함께 명시합니다.

입력 근거, 출처·수집 시각, 모델 정보, 반복·시드, 검증 전 행동 가정을 리포트에 남기고 민감도 분석으로 결론이 달라지는 범위를 확인하세요. 민감도 분석의 정책 순위 안내는 기존과 같이 평균 대기시간 기준입니다.

## 6 재현에 필요한 자료

- 같은 초기 상태·A/B·종류·기본 단가·대표 출력과 수집 시각.
- 같은 `forecastPlan`: 모델 생성·실제 시작·남은 구간·기대 건수·구간별 이용률. 시각을 옮겨 실행하면 같은 시드라도 다른 실험입니다.
- 같은 `sessionPlan`: 공개 history 고정 커밋·파일·30일 기준 시각·정제·표본·대체 수준·시간 분포. 표본이 늘어나면 결과도 바뀝니다.
- E·행동계수 묶음·할인/할증/여유 기준·방향별 도로 거리·반복·시드.
- HTML/CSV의 입력 근거와 수집 초기·지역 이전·잔여·전력 근사 한계.

평가 범위는 **A의 충전량과 15분 평균 등가 부하 피크 변화**이며, B와 A+B의 부하 변화도 함께 기록합니다. 정책 선택에는 대기·추가 거리·요금·단순 매출도 사용합니다. 모든 정책의 수요와 초기 난수는 같지만, 충전량·시간 방식의 민감도 수준을 바꾸면 시간·초기 잔여·등가 전력도 그 규칙으로 다시 계산됩니다.

## 팀 채택 기준의 실행·보고

2026-11-05 채택한 급속 행동계수 s=1(정규화), α=950원/km, β=360원/분, τ=7200원을 실제 화면과 기본 급속 엔진 실행에 적용합니다. 완속에는 잠정 s=1, α=510원/km, β=220원/분, τ=10000원을 적용합니다. 국내 일반 통행시간 가치·미국 Level 2 대기 WTP·영국 야간 1회 요금 계수의 조합으로 공동 추정값이 아닙니다. 기존 예시 1/600/300/2000은 두 종류 모두 비교용입니다. 수동 수정은 사용자 가정으로 표시합니다. 정책 기본값은 20/15/50%를 유지하고 팀 지정 비교 수준은 할인 10/20/30%, 할증 0/15/30%, 여유 빈 비율 30/50/70%로 제공합니다. 최적 정책 확정값이 아닙니다.

제주 E(급속 14.82/완속 16.24kWh, 0.5/1/1.5배 민감도), 완료 세션 경험분포, Durrett(2012) 정상상태 잔여 방식도 팀 기준입니다. 시간·E 계산은 기존 구현과 같으며 행동 기본값과 채택 상태·근거를 갱신했습니다. [일곱 항목의 채택 이유·네 가지 연구 한계·문헌](behavior-presets.md#2026-11-05-팀-채택-이유)을 확인하세요.

리포트 근거표와 HTML/CSV에는 행동계수 채택일·버전(급속 team-2026-11-05-v1, 완속 team-2026-11-05-slow-v1), 원문·환산 가정, 지역/충전 환경 차이·30km/h 거리 환산·대기 항 축약·국내 독립 검증 부재를 남깁니다. 완료 기록 모드에는 Durrett 서지·저자 공개 초고·정상상태 가정도 기록합니다. 예전 기본값 결과와 새 결과의 차이를 정책 개선 효과로 섞지 말고 같은 입력 아래 기존/채택 묶음을 비교하세요.

## 팀 정책 비교와 적용 건수

‘추천 비교값 넣기’는 할인율 **10/20/30%**, 혼잡 할증률 **0/15/30%**, 여유 판정 빈 비율 **30/50/70%**를 넣습니다. 다른 숫자 항목은 현재값의 0.5/1/1.5배이며 현재 기준값은 자동 포함합니다. 비교 수준은 최적값이나 신뢰구간이 아닙니다. 한 항목씩 비교한 뒤 후보 정책 묶음을 같은 조건에서 실행하세요.

- 할인 증가 시 선택·대기뿐 아니라 평균 충전요금·단순 매출·실제 할인 적용 건수를 확인합니다. 할증은 0%와 비교하고 이용자 부담과 B의 추가 혼잡도 함께 봅니다.
- **할인/할증 적용 신규 세션(건/회)**은 선택한 단가가 해당 충전소 기본 단가보다 낮거나 높은 신규 차량 수의 반복 평균입니다. 할인율·할증률 0%이면 적용 건수도 0입니다. AI v2에서는 각 도착 구간 단가로 집계하며 초기 차량은 제외합니다. 관측 성과·지역 전체 할인 대상 충전소 수가 아닙니다.
- 여유 판정은 빈 충전기 비율 기준입니다. 0%/100%처럼 어느 비교 수준에서도 상태가 같은 A/B는 경계 효과를 보여 주지 못할 수 있습니다. 중간 이용률의 구간을 확인하세요. 현재 도구는 선택한 두 곳을 평가하며 지역 전체 할인 대상 수·비율을 산출하지 않습니다.
- 같은 종류·유사한 충전기 수/수요 규모·접근 가능한 A/B와 같은 자료 시점을 사용합니다. 방향별 경로·출입구·진입 제한·대표 출력 출처도 검토합니다.
- A 피크 감소와 **동시 A+B 합산 피크 감소**를 구분하고 B 피크·총충전량·기간 이후 에너지·대기·요금·매출을 함께 보고합니다. 대표 출력/총시간의 일정 등가 전력은 실측 충전곡선·효율 손실·출력 공유를 재현하지 않습니다.
- 반복 **100회**, 시드 **42**를 기준으로 하고 예를 들어 7·2026 등 다른 시드에서도 정책 방향이 유지되는지 별도 실행합니다. 시드를 바꿀 때도 예측 계획·상태·완료 기록은 고정해야 합니다. 최신 연결로 자료 시각까지 바뀌면 순수 시드 비교가 아닙니다.

각 비교값의 [선정 근거와 적용 범위](simulation-parameters.md#정책-비교-수준의-문헌-근거)를 참고하세요. 실측 에너지와 전력 시계열을 확보하면 동일 시간 구간에서 총 kWh와 15분 평균 kW를 각각 대조합니다. 현재는 `충전량 ÷ 보정 총시간`으로 등가 전력을 구하며 대표 출력은 충전시간 하한과 용량 기준에 사용합니다.
