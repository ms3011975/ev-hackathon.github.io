## 팀에서 정할 사항

**확정된 현실 대표값은 아직 아닙니다. 행동계수는 관측 행동을 설명하도록 보정하고, 요금 정책은 그 조건에서 효과를 비교해 선택합니다.** 정책 성과가 좋아지는 계수를 골라 행동 추정값으로 삼지 않습니다.

### 팀원 1 · 행동계수와 입력 자료의 근거

| 항목 | 현재값 / 선택 가능한 후보 | 결정할 것·필요한 근거 | 제출 결과 |
|---|---|---|---|
| 가격 민감도 s | 기존·문헌 모두 1 | 우선 1로 정규화할지. 실제 가격 반응을 추정한 1배가 아님 | 척도 고정 원칙 |
| 이동 비용 α | 기존 600 / 문헌 950원/km | 우회 부담의 선택 기록·설문 또는 문헌 이전 가능성 | 기준·비교 범위·단위·출처 |
| 대기 비용 β | 기존 300 / 문헌 360원/분 | 대기 부담의 선택 기록·설문 또는 문헌 이전 가능성 | 기준·비교 범위·단위·출처 |
| 선택 다양성 τ | 기존 2000 / 문헌 7200원 | 종합 비용 차이에 선택이 반응하는 정도. s·α·β와 상대 척도로 검토 | 기준·비교 범위·추정 한계 |
| 건당 충전량 E | 제주 급속 14.82 / 완속 16.24kWh | 지역·시기·차종 이전과 전 차량 평균 일괄 적용을 인정할지 | 채택 이유, 0.5/1/1.5배 등 시나리오 범위 |
| 신규 충전시간 | 완료 기록 경험분포 | 30일·1~1440분·최소 5건·충전소→지역→출력 대체 규칙 검토 | 유효 표본·누락/대체·원평균/보정평균 |
| 초기 잔여시간 | 길이 비례 표본+균등 잔여 | 현재 시작시각 없이 정상상태 추정하는 한계 검토 | 추정 방법 채택 이유·비교 결과 |

먼저 급속에서 **기존 묶음 1/600/300/2000과 문헌 묶음 1/950/360/7200**을 비교합니다. 이후 한 항목씩 바꾸는 분석은 탐색 시나리오이며 문헌의 신뢰구간이 아닙니다. 완속에는 급속 문헌 후보를 검증값처럼 이전하지 않습니다. 같은 비율로 s·α·β·τ를 모두 바꾸면 선택 확률이 같아 척도를 따로 정해야 합니다.

### 팀원 2 · 요금 정책과 피크 평가

| 항목 | 현재값 | 우선 비교할 예시·판단 기준 | 제출 결과 |
|---|---|---|---|
| 여유 할인율 | 20% | 10/20/30%; 분산·대기·추가 이동·이용자 요금·단순 매출 | 채택 후보와 감수할 매출 변화 |
| 혼잡 할증률 | 15% | 0/15/30%; 이용자 부담과 정책 효과 | 할증 사용 여부·상한·선정 이유 |
| 여유 판정 기준 | 빈 비율 50% | 30/50/70%; 혼잡 경계가 아니라 할인 대상 경계 | 할인 조건과 실제 대상 구간 |
| 비교할 A/B·시간대 | 실행마다 수집 상태에서 선택 | 같은 종류, 접근 가능성·충전기 수·수요 규모·자료 시각 | ID·속도·시각·선정 이유 |
| 도로 거리 대리값 | 방향별 자동 조회 | 출입구·진입 제한 확인, 충전소 사이 거리=추가 우회거리 가정 검토 | 방향별 거리·오차·수동 대체 이유 |
| 전력 근사 | E/보정 총시간의 일정 등가 전력 | 대표 kW의 출처·혼합 출력·충전곡선/효율/공유 제외 검토 | 실측 전력과의 차이 및 채택 범위 |
| 피크 평가 | A/B·동시 A+B의 15분 평균 등가 부하 | A 감소와 합산 감소 구분, 대기·기간 이후 에너지 함께 확인 | 공통 지표·정책 선정 기준 |
| 반복·시드 | 100회·42 | 공통 조건 고정, 다른 시드에서도 결론 확인 | 재현 가능한 입력·HTML/CSV |

위 정책 숫자는 **실험용 비교 수준**이며 적정값·최적값으로 입증된 범위가 아닙니다. 한 항목씩 바꾼 뒤 후보 정책 묶음을 일반 실행으로 다시 확인합니다. 이미 0%/100% 이용률인 거점은 여유 기준만 바꿔도 상태가 안 바뀔 수 있어 중간 이용률 구간도 확인합니다. 민감도 화면의 정책 순위 안내는 평균 대기 기준이며 피크 최적 정책 판정이 아닙니다.

### 두 팀원이 함께 고정할 입력과 완료 기준

- 같은 충전소 상태·AI 예측 계획·시작 시각·완료 기록 버전·도로 거리·종류·E·반복·시드를 공유합니다. 시드만 같고 자료나 시작 시각이 다르면 같은 실험이 아닙니다.
- AI v2가 유효하면 **신규 명수·도착 기간은 자동 입력**입니다. 수동 24명·60분은 예시 시나리오이며 AI 예측값으로 보고하지 않습니다.
- 충전 시작 건수를 실제 도착 수요의 대용으로 사용한다는 점, 구간 내 균등 도착·독립 포아송·포기 없음·이동시간 미반영을 채택할지 합의합니다. 현재 UI에 분포·초기 잔여·평균 전력을 직접 조절하는 별도 숫자 입력은 없습니다. 규칙을 바꾸려면 코드 변경이 필요합니다.
- 각 값에 **값/단위·출처·대상 지역/표본·환산 가정·채택 이유·비교 범위·미확정 한계**를 기록합니다. 행동계수 근거표와 정책 비교 HTML/CSV를 제출합니다.
- 결과는 ‘특정 입력 아래의 충전 부하 집중 모의 변화’로 표현합니다. 검증되지 않은 값을 최적값·충북 대표값·실측 배전망 저감 성과로 표현하지 않습니다.
- 실험 전에 모델 제공 담당자와 공개 결과의 생성·수집·배포 갱신을 확인합니다. 연결 버튼은 원본 모델 실행 버튼이 아닙니다.

## AI 연결 필요·실패 표시를 읽는 법

v2에서 예측이 없거나 검증되지 않으면 인원·기간을 비우고 **AI 예측 확인 필요**를 표시합니다. 연결 중에는 ‘불러오는 중’, 성공하면 ‘추정값’과 자동값으로 바뀝니다. 기존 24/60 같은 수동값은 예측으로 사용하지 않습니다. 수동 모드로 돌아가면 이전 수동 입력을 복원합니다.

연결 상태에는 실패 이유와 수신 생성 시각을 표시합니다. 예측 생성 후 90분 초과, 상태 수집 후 45분 초과, 남은 구간 1분 미만, 선택 A/B·종류 누락 등이면 차단합니다. 최신 URL을 재조회해도 같은 생성 시각이면 원본 데이터가 갱신되지 않은 상태일 수 있습니다. [진단 순서](simulation-report.md#연결이-안-될-때)를 따릅니다. 만료를 피하려고 JSON 시각을 바꾸지 않습니다.

## 1. 먼저 알아둘 사항

**현재 기본값은 실측으로 보정한 충북 운전자 대표값이나 최적 정책이 아닙니다.** 차량당 충전량은 제주 건별 이력의 급속/완속 평균을 이전 적용한 추정값입니다. 신규 운전자 수·행동계수 등은 최초 요구사항의 예시값으로 시작했습니다. 할인·할증율과 여유 기준은 기존 프로젝트 정책의 기본값을 사용합니다.

사이트의 값은 다음처럼 구분합니다.

| 구분 | 해당 값과 의미 |
|---|---|
| 실측·수집값 | 실제 모드의 충전소 위치·충전기 상태. 표시된 수집 시각의 기록이며 현재 상태 보장 아님 |
| 추정값 | 제주 자료 기반 충전량·완료 기록 기반 신규 시간/초기 잔여·문헌 환산 후보·도로 경로 거리·대표 출력·대체 단가·외부 AI 예측 등. 통계 보정 완료를 의미하지 않음 |
| 가정값 | 수동 운전자 수·직접 입력 충전량·기존/사용자 행동계수·간소화 시간 등 검증 전 입력. 기록 기반 초기 잔여도 정상상태 가정을 포함하는 추정값. 예시 충전소도 가정값 |
| 공시값 | 운영사 요금표의 해당 구간 기본 단가. 실제 이용자 청구액과 다를 수 있음 |
| 정책 설정 | 할인율·할증율·여유 판정 기준 |
| 실험 설정 | 반복 횟수·난수 시드 |

예측·추정과 가정은 구분해야 합니다. v1 이용률은 요금에 적용하고 v2는 구간별 이용률과 신규 충전 시작 건수 추정으로 수요를 생성합니다. 행동계수는 가정값이며, 충전량은 제주 추정값 또는 사용자 가정값을 선택합니다.

## 3. 운전자 선택 계산

행동계수 선택과 두 설정 동시 비교는 [기존 예시값·문헌 환산 후보 안내](behavior-presets.md)를 참고하세요. 문헌 후보는 급속용 `s=1, α=950, β=360, τ=7200`이며 국외 연구를 고정 참조 조건으로 환산한 추정입니다. 아래 설명의 행동계수 기본 숫자는 초기 선택인 기존 예시값을 뜻합니다. 직접 수정한 계수는 사용자 가정값입니다.

운전자가 도착하면 각 충전소의 종합 비용을 계산합니다.

```text
C_i = s × E × P_i + α × D_i + β × W_i

s   : 가격 민감도
E   : 충전량(kWh)
P_i : 충전소 단가(원/kWh)
D_i : 추가 거리(km)
W_i : 선택 시점의 예상 대기(분)
```

거리가 멀거나 기다려야 하는 부담을 요금과 비교할 수 있도록 원화로 환산한 것입니다. 거리·대기 환산액은 실제 청구하는 금액이 아닙니다. 결과의 평균 충전요금에는 `E × P_i`만 포함합니다.

### 3.1 가격 민감도: 요금 차이를 얼마나 중요하게 보는가

기본값은 **1배**이며 충전요금 항에만 곱합니다.

- 0배: 선택할 때 충전요금을 무시합니다. 충전요금 자체를 무료로 바꾸지는 않습니다.
- 0.5배: 충전요금 차이를 기본의 절반만큼 반영합니다.
- 1배: 충전요금 차이를 그대로 반영합니다.
- 2배: 충전요금 차이를 두 배 크게 반영합니다.

예를 들어 B가 차량당 2,000원 저렴하다면, 2배 설정에서는 그 차이를 선택 계산상 4,000원으로 반영합니다. 실제 청구액이나 결과의 평균 충전요금에 2배를 곱하는 것은 아닙니다.

같은 거리·대기 조건에서 가격 민감도를 높이면 더 저렴한 충전소의 선택 확률이 높아집니다. 전체 실험에서는 선택이 대기열을 바꾸므로 평균 대기까지 반드시 줄어드는 것은 아닙니다.

### 3.2 이동 비용 α: 더 멀리 가는 부담

기본값은 **600원/km**입니다.

```text
추가 거리 2km × 600원/km = 이동 부담 1,200원
```

- 클수록 추가 거리가 있는 B를 선택하기 어려워집니다. 단, 같은 시점의 다른 비용이 같다는 조건입니다.
- 작을수록 할인이나 짧은 대기를 위해 추가 이동을 받아들이기 쉬워집니다.
- 0이면 추가 거리를 선택 비용에서 제외합니다.

600원은 실제 주행 전기료로 측정한 값이 아니라 불편함 등을 표현하는 가정 계수입니다. 수동/v1에서는 A가 원래 목적지입니다. v2는 원래 A/B 선택지를 보존하며 다른 쪽으로 바꿀 때만 방향별 추가 거리를 적용합니다.

### 3.3 대기 비용 β: 기다리는 부담

기본값은 **300원/분**입니다.

```text
예상 대기 10분 × 300원/분 = 대기 부담 3,000원
```

- 클수록 다른 비용이 같을 때 대기가 짧은 충전소를 선호합니다.
- 작을수록 기다리는 대신 저렴하거나 가까운 곳을 선택하기 쉬워집니다.
- 0이면 선택할 때 예상 대기를 무시하지만, 선택 후 실제 대기는 발생할 수 있습니다.

예를 들어 B가 2km 멀지만 10분 덜 기다린다면 현재 계수에서 이동 부담은 1,200원 증가하고 대기 부담은 3,000원 감소합니다. B의 종합 부담이 1,800원 낮아지며 여기에 충전요금 차이를 더합니다. 이 금액은 실제 대기료가 아닙니다.

### 3.4 선택 다양성 τ: 비용 차이에 얼마나 뚜렷하게 반응하는가

기본값은 **2,000원**이며 양수여야 합니다. 종합 비용이 낮은 충전소를 고를 확률을 다음처럼 계산합니다.

```text
Prob(i) = exp(-C_i / τ) ÷ Σ exp(-C_j / τ)
```

구현에서는 최솟값을 뺀 안정적인 계산을 사용합니다. 비용 차이로 확률이 정해지므로 모든 비용에 같은 금액을 더해도 확률은 같습니다.

- τ가 작으면 비용이 낮은 충전소에 선택이 강하게 집중됩니다.
- τ가 크면 비용 차이에 덜 뚜렷하게 반응하고 A/B 선택 확률이 비슷해집니다.
- A/B 비용이 같으면 τ에 관계없이 50%씩입니다.

아래는 **한 운전자의 선택 시점에** A 종합 비용이 12,000원, B가 10,000원이라는 가정 예시입니다.

| τ | B 선택 확률 |
|---:|---:|
| 1,000원 | 약 88.1% |
| 2,000원 | 약 73.1% |
| 4,000원 | 약 62.2% |

τ는 운전자 수·추가 청구액이 아닙니다. 가격 민감도가 충전요금 항만 조절하는 반면, τ는 **가격·거리·대기를 합친 종합 비용 차이 전체**에 작용합니다. 현재는 모든 운전자에게 공통 행동계수를 적용하고 선택을 확률적으로 처리합니다. 개인별 실제 선호를 학습한 모델은 아닙니다.

행동계수를 추정할 때는 가격계수·α·β·τ의 상대적 척도를 함께 고려해야 합니다. 모든 비용계수와 τ를 같은 비율로 키우면 같은 선택 확률이 되므로 각각을 독립적으로 식별할 수 있다고 가정해서는 안 됩니다.

## 4. 수요와 충전시간 가정

### 4.1 신규 운전자 수

수동 모드 기본 **24명**은 앞으로 새로 오는 차량 수의 예시 가정입니다. 시작 시 이미 충전 중인 차량은 포함하지 않습니다. 차량이 많아질수록 처리 능력에 비해 수요가 커져 대기가 발생하기 쉽습니다. 선택한 충전소의 가동 대수와 점유시간에 따라 같은 24명의 수요 압력도 달라집니다.

v1 이용률 입력은 신규 운전자 수를 바꾸지 않습니다. v2는 제공된 구간별 기대 충전 시작 건수로 A/B 원래 선택지별 포아송 차량을 생성합니다. 기대값과 생성 평균은 다를 수 있으며 실제 도착·대기·포기 차량은 관측하지 않습니다.

### 4.2 도착 생성 기간

수동 모드 기본 **60분** 안에서 운전자별 도착 시각을 균등분포로 생성한 뒤 도착순으로 처리합니다. 정확한 등간격 도착이 아니므로 일부 시간에 몰릴 수 있습니다.

같은 인원을 30분 안에 도착시키면 120분에 나눠 도착시키는 것보다 수요가 집중됩니다. 이 값은 전체 차량의 충전을 종료시키는 시각이 아닙니다. 기간 내 도착한 차량은 종료 시점 이후에 끝나더라도 모두 집계합니다.

### 4.3 차량당 충전량

기본은 **급속 14.82kWh / 완속 16.24kWh**이며 모든 신규 차량에 동일하게 적용합니다. 2021~2022년 제주 건별 이력의 양수 충전량 평균으로, 충북 실측값이 아닌 이전 적용 추정값입니다. 원본의 단위 미기재, 버스 전용·0kWh·중복 제외 기준, 건수와 계산은 [제주 충전량 산출 근거](jeju-energy.md)를 확인하세요. 직접 수정한 값과 민감도 분석의 변경 수준은 가정값입니다. 충전량이 커지면 차량당 요금과 충전소 간 단가 차이의 금전적 효과가 커집니다.

예를 들어 단가 차이가 50원/kWh라면 10kWh에서는 차량당 500원, 30kWh에서는 1,500원 차이입니다. 충전시간 변화 여부는 아래 모드에 따라 다릅니다.

### 4.4 신규 차량 충전시간

실제 데이터 화면 기본은 **완료 기록 기반 `sessions`**입니다. 예시 모드와 자료 없는 저수준 엔진 기본은 `power`입니다. 엔진에서 `sessions`를 사용할 때는 선택 A/B와 일치하는 `sessionPlan`이 필요합니다.

| 방식 | 신규 시간 | 초기 잔여 |
|---|---|---|
| `sessions` | 완료 기록 경험분포에서 추출 후 최소시간 보정 | 보정 총시간의 길이 비례 표본 + 균등 잔여 비율 |
| `power` | `60×E/대표kW`분 | 0~해당 총시간 균등분포 |
| `assumed` | 20~40분 균등분포 | 0~30분 균등분포 |

완료 기록은 [공개 history 브랜치](https://github.com/ev-hackathon/ev-hackathon.github.io/tree/history/history/sessions)의 지역별 CSV입니다. 초기 상태 수집 시각을 기준으로 최근 30일 종료 세션만 사용하며 이후 기록은 제외합니다. 1~1440분, 시작·종료·minutes 일치, 중복·충돌을 검사합니다. 해당 충전소·종류 5건 이상, 부족하면 같은 지역·종류 5건 이상, 모두 부족하면 출력 기반 가정으로 대체하고 표시합니다. 5건은 최소 처리 규칙이며 신뢰성 인증이 아닙니다.

kWh가 기록에 없으므로 별도 E를 유지합니다. 추출 시간이 너무 짧으면 **`보정 총시간=max(기록 시간,60×E/대표kW)`**로 연장합니다. 세션의 일정 등가 전력은 `60×E/보정 총시간`입니다. 원평균·분위수와 적용 평균을 구분하고 원표본 연장 수·결과의 연장 차량 수도 표시합니다. E를 바꾸면 짧은 시간 보정과 잔여 추정도 달라질 수 있습니다.

기록은 기기 보고 세션 길이이며 비충전 점유가 포함될 수 있습니다. 충전소·시간대·차종 구성과 수집 초기/기기별 편향이 남습니다. 대표 출력은 개별 순간 출력을 보장하지 않으며, 실제 충전곡선·효율·출력 공유는 제외합니다. v2 JSON의 평균 시간은 참고용이고 `sessions`는 별도 조회한 원기록 분포를 사용합니다.

### 4.5 초기 차량의 잔여 충전시간

연결된 공개 자료에는 **현재 진행 중 세션의 시작시각이 없습니다.** 완료 기록으로 특정 초기 차량의 잔여시간을 실측 복원할 수는 없습니다.

`sessions`는 총시간이 긴 세션일수록 임의 시점에 점유 중 관측되기 쉽다는 정상상태를 가정합니다. 보정 총시간 T에 비례해 표본을 선택하고 `R=U×T`(U는 0~1 균등)로 잔여를 생성합니다. 기대 잔여는 `ΣT²/(2ΣT)`이며 단순 평균 총시간의 절반과 다릅니다. 긴 꼬리 때문에 신규 평균보다 잔여 기대가 클 수도 있습니다. 표본이 없으면 `power`와 같은 균등 잔여로 대체합니다.

초기 차량에도 별도 E를 총 세션 에너지로 가정합니다. 등가 전력은 `60×E/T`, 잔여 에너지는 `E×R/T`입니다. 실제 잔여 kWh·현재 시작시각·실측 전력은 아닙니다. 화면에서 별도 잔여 숫자를 입력하는 항목은 없으며 시간 방식을 바꾸어 비교합니다. 표본 출처 커밋·기준 시각·정제·대체·보정값은 근거표와 리포트에 보존합니다.

## 5. 거리 가정

### 양방향 도로 거리와 산정 방식

- 도로 방식: OSM 도로망과 OSRM car로 A→B, B→A 경로를 각각 계산합니다. 실시간 교통·실제 출입구 경로를 보장하는 실측값은 아닙니다. 실패 시 직선거리로 바꾸지 않고 재조회·수동 입력을 안내합니다.
- 사용자 입력: 입력한 km를 양방향 동일하게 사용합니다. 예시의 2km는 고정된 실제 도로 거리가 아닙니다.

추가 거리가 길면 `α × 거리`가 커집니다. 수동/v1에서는 A가 원래 목적지이므로 A 추가 거리는 0km, B로 바꾸면 A→B 거리입니다. v2에서는 원래 선택지 A/B에서 다른 곳으로 바꾸는 방향의 거리를 사용합니다. 출발지·최종 목적지가 없어 실제 우회거리를 충전소 사이 거리로 대체하는 가정이 남습니다. 이동시간은 도착 시각에 더하지 않습니다. [도로 거리 출처·한계와 팀 역할](road-distance.md)을 참고하세요.

민감도 분석에서 거리 수준을 변경하면 사용자 입력 거리로 취급해 양방향 동일 가정값을 적용합니다. 기준 수준은 원래 방향별 도로 거리를 유지합니다.

## 6. 요금 정책 설정

### 6.1 여유 판정 대기율

**대기율은 기다리는 차량 비율이 아니라 빈 충전기 비율입니다.**

```text
대기율 = 빈 충전기 / (빈 충전기 + 충전 중인 충전기)
이용률 = 충전 중인 충전기 / (빈 충전기 + 충전 중인 충전기)
```

사용 불가·미확인 충전기는 처리 능력에서 제외합니다. 기본 대기율 기준 50%에서는 다음처럼 판정합니다.

| 상태 | 조건 |
|---|---|
| 여유 | 빈 충전기 비율 50% 이상 |
| 보통 | 빈 충전기가 있지만 비율이 50% 미만 |
| 혼잡 | 가동 가능한 충전기가 모두 충전 중, 즉 이용률 100% |
| 불가·미확인 | 처리 가능한 충전기가 없는 경우 |

화면의 기준은 여유↔보통 경계를 바꿉니다. 혼잡 조건을 이용률 80% 등으로 바꾸는 설정은 현재 없습니다. 모든 충전기가 비어 있는 B는 여유 기준을 30/50/70%로 바꿔도 계속 여유일 수 있습니다.

### 6.2 할인율과 할증율

기본 여유 할인율은 **20%**, 혼잡 할증율은 **15%**입니다. 할인율·할증율이 아니라 각 충전소의 기본 단가가 실제 요금표에서 옵니다.

| 정책 | 여유 | 보통 | 혼잡 |
|---|---:|---:|---:|
| 고정요금 | 기본 × 1 | 기본 × 1 | 기본 × 1 |
| 할인·할증 | 기본 × (1−할인율) | 기본 × 1 | 기본 × (1+할증율) |
| 할인 전용 | 기본 × (1−할인율) | 기본 × 1 | 기본 × 1 |

단가는 기존 관제처럼 소수 첫째 자리로 반올림합니다. 수동/v1은 시작 상태 또는 한 시점 예측으로 단가를 고정합니다. v2는 제공된 각 구간의 이용률로 단가를 정하고 차량은 선택 시 단가를 적용합니다. 시뮬레이션에서는 관제의 시간대 배수를 적용하지 않습니다.

할인을 크게 하면 다른 조건이 같을 때 해당 충전소를 선택하기 쉬워지지만, 그곳에 대기열이 생길 수 있어 전체 대기 감소가 보장되지는 않습니다. 관제 탭의 정책 슬라이더와 시뮬레이션 입력은 독립적입니다.

## 7. 실험 설정

### 7.1 반복 횟수

기본 **100회**입니다. 반복마다 도착 시각·선택 난수·필요한 시간 가정을 생성하고 결과 평균을 냅니다. 한 반복의 세 정책은 같은 운전자 조건을 공유합니다.

반복을 늘리면 무작위 표본에 따른 평균의 흔들림을 줄일 수 있지만 잘못된 행동 가정이나 데이터 편향을 고쳐주지는 않습니다. 결과의 표준오차는 반복 간 변동이며 실제 미래 예측오차가 아닙니다.

### 7.2 난수 시드

기본 **42**는 재현성을 위한 번호이며 값 자체에 현실적 의미는 없습니다. 같은 충전소 데이터·예측·설정·시드에서는 같은 결과가 나옵니다. 실제 데이터나 외부 예측이 달라졌다면 시드만 같다고 같은 실험은 아닙니다.

## 8. 외부 AI 예측을 사용할 때

`요금·수요 기준`에서 v1 또는 v2를 선택하면 A/B의 같은 종류 예측으로 상태를 판정합니다. 예측 이용률이 `u`라면 예상 빈 충전기 비율은 `1-u`입니다. v2 원클릭 연결·시간 정렬·생성 방식은 [실제 모델 연결 설명](simulation-report.md#실제-제공-모델-연결)을 참고하세요.

기본 기준에서 예측 이용률 20%는 여유, 80%는 보통, 100%는 혼잡입니다. v1은 정책 단가에만 반영합니다. v2는 구간별 이용률과 제공된 시작 건수 추정으로 차량을 생성하고 선택 시 단가를 적용합니다. 초기 점유는 수집 상태입니다. 충전량·행동계수·미래 대기열을 이용률에서 만들어내지 않습니다.

외부 모델 예측의 ID·급속/완속·값 범위·생성/대상 시각을 검증합니다. 형식 검증을 통과했다고 모델 정확도까지 검증한 것은 아닙니다. v1 대상 시각은 실행 시점보다 미래여야 합니다. v2는 생성 후 90분·상태 45분·남은 구간 1분 이상을 검사합니다. 기대 건수·기간은 검증된 남은 구간에서 자동 입력합니다.

## 9. 결과 해석과 근거 보강

- 가상 선택과 대기는 실제 분산 실적이나 배전망 피크 저감 성과가 아닙니다.
- 총 할인액은 이용자 혜택 합계이며 사업자 순손실과 다릅니다. 수입 차이는 비용을 반영하지 않은 단순 충전 매출 비교입니다.
- 선택 당시 예상 대기와 실제 대기를 구분해 계산하지만, 정보가 정확하고 취소·이탈이 없는 현재 모델에서는 일치합니다.
- 대기열은 도착순으로 충전기에 배정하며 취소·포기·예약·다른 충전소로 재이동은 없습니다.
- 민감도 분석은 한 항목씩 바꾸는 비교입니다. 여러 항목의 상호작용이나 실제 정확성을 검증하는 기능은 아닙니다.
- 수요·충전 특성은 실제 이력의 통계·분포로, 행동계수는 실제 선택 기록 또는 선택 실험 설문으로 보강할 수 있습니다. 자료가 없으면 가정값과 출처·범위를 명시합니다.
- 강화학습은 요금 정책을 선택하는 용도로 검토할 수 있지만, 시뮬레이션 성과가 커지도록 행동계수를 고르는 것이 실측 보정은 아닙니다.

보고서에는 충전소 ID·수집 시각·외부 예측 정보·입력값·시드·비교 범위·모델 가정을 함께 남기세요. 사이트의 일반 결과 및 민감도 CSV에 근거표와 조건을 함께 저장할 수 있습니다.

## 10 충전 부하 리포트

일반 실행 후 A/B 및 합산 15분 평균 등가 부하, 반복별 피크 평균, 고정요금 대비 저감률, 도착 기간 이후 충전량을 확인할 수 있습니다. 단일 HTML 리포트와 시계열 CSV 다운로드를 지원합니다. 민감도 분석에서도 수준별 피크를 비교합니다.

부하는 충전량과 모의 충전시간으로 계산합니다. `sessions`는 짧은 기록 시간을 최소 필요시간까지 연장해 대표 출력 초과를 막고 초기 전력을 E/보정 총시간으로 계산합니다. `power`는 E/대표 출력으로 시간을 정하는 비교 방식입니다. 20~40분 가정에서는 대표 출력 초과가 발생할 수 있어 리포트에 표시합니다. 초기 잔여 에너지는 완료 기록 모드에서 E×잔여/총시간, 다른 모드에서 대표 출력×가정 잔여시간입니다. 실제 배전망 저감 실적은 아닙니다. 상세 계산과 모델 출력 예시는 [AI 출력 계약과 부하 리포트](simulation-report.md)를 참고하세요.
