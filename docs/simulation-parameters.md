## 1. 먼저 알아둘 사항

**현재 기본값은 실측으로 보정한 충북 운전자 대표값이나 최적 정책이 아닙니다.** 신규 운전자 수·충전량·행동계수 등은 최초 요구사항의 예시값으로 시작했습니다. 할인·할증율과 여유 기준은 기존 프로젝트 정책의 기본값을 사용합니다.

사이트의 값은 다음처럼 구분합니다.

| 구분 | 해당 값과 의미 |
|---|---|
| 실측·수집값 | 실제 모드의 충전소 위치·충전기 상태. 표시된 수집 시각의 기록이며 현재 상태 보장 아님 |
| 추정값 | 좌표 직선거리·대표 출력·대체 단가·외부 AI 예측 등. 통계 보정 완료를 의미하지 않음 |
| 가정값 | 운전자 수·충전량·행동계수·초기 잔여시간 등 검증 전 시나리오 입력. 예시 충전소도 가정값 |
| 공시값 | 운영사 요금표의 해당 구간 기본 단가. 실제 이용자 청구액과 다를 수 있음 |
| 정책 설정 | 할인율·할증율·여유 판정 기준 |
| 실험 설정 | 반복 횟수·난수 시드 |

예측·추정과 가정은 구분해야 합니다. v1 이용률은 요금에 적용하고 v2는 구간별 이용률과 신규 충전 시작 건수 추정으로 수요를 생성합니다. 행동계수와 충전량은 계속 가정값입니다.

## 3. 운전자 선택 계산

운전자가 도착하면 각 충전소의 종합 비용을 계산합니다.

```text
C_i = s × E × P_i + α × D_i + β × W_i

s   : 가격 민감도
E   : 충전량(kWh)
P_i : 충전소 단가(원/kWh)
D_i : 추가 거리(km)
W_i : 선택 시점의 예상 대기(분)
```

거리가 멀거나 기다려야 하는 부담을 요금과 비교할 수 있도록 원화로 환산한 것입니다. 거리·대기 환산액은 실제 청구하는 금액이 아닙니다. 결과의 평균 충전요금에는 `E × P_i`만 포함합니다.

### 3.1 가격 민감도: 요금 차이를 얼마나 중요하게 보는가

기본값은 **1배**이며 충전요금 항에만 곱합니다.

- 0배: 선택할 때 충전요금을 무시합니다. 충전요금 자체를 무료로 바꾸지는 않습니다.
- 0.5배: 충전요금 차이를 기본의 절반만큼 반영합니다.
- 1배: 충전요금 차이를 그대로 반영합니다.
- 2배: 충전요금 차이를 두 배 크게 반영합니다.

예를 들어 B가 차량당 2,000원 저렴하다면, 2배 설정에서는 그 차이를 선택 계산상 4,000원으로 반영합니다. 실제 청구액이나 결과의 평균 충전요금에 2배를 곱하는 것은 아닙니다.

같은 거리·대기 조건에서 가격 민감도를 높이면 더 저렴한 충전소의 선택 확률이 높아집니다. 전체 실험에서는 선택이 대기열을 바꾸므로 평균 대기까지 반드시 줄어드는 것은 아닙니다.

### 3.2 이동 비용 α: 더 멀리 가는 부담

기본값은 **600원/km**입니다.

```text
추가 거리 2km × 600원/km = 이동 부담 1,200원
```

- 클수록 추가 거리가 있는 B를 선택하기 어려워집니다. 단, 같은 시점의 다른 비용이 같다는 조건입니다.
- 작을수록 할인이나 짧은 대기를 위해 추가 이동을 받아들이기 쉬워집니다.
- 0이면 추가 거리를 선택 비용에서 제외합니다.

600원은 실제 주행 전기료로 측정한 값이 아니라 불편함 등을 표현하는 가정 계수입니다. A는 원래 목적지로 가정해 추가 거리 0km를 적용합니다.

### 3.3 대기 비용 β: 기다리는 부담

기본값은 **300원/분**입니다.

```text
예상 대기 10분 × 300원/분 = 대기 부담 3,000원
```

- 클수록 다른 비용이 같을 때 대기가 짧은 충전소를 선호합니다.
- 작을수록 기다리는 대신 저렴하거나 가까운 곳을 선택하기 쉬워집니다.
- 0이면 선택할 때 예상 대기를 무시하지만, 선택 후 실제 대기는 발생할 수 있습니다.

예를 들어 B가 2km 멀지만 10분 덜 기다린다면 현재 계수에서 이동 부담은 1,200원 증가하고 대기 부담은 3,000원 감소합니다. B의 종합 부담이 1,800원 낮아지며 여기에 충전요금 차이를 더합니다. 이 금액은 실제 대기료가 아닙니다.

### 3.4 선택 다양성 τ: 비용 차이에 얼마나 뚜렷하게 반응하는가

기본값은 **2,000원**이며 양수여야 합니다. 종합 비용이 낮은 충전소를 고를 확률을 다음처럼 계산합니다.

```text
Prob(i) = exp(-C_i / τ) ÷ Σ exp(-C_j / τ)
```

구현에서는 최솟값을 뺀 안정적인 계산을 사용합니다. 비용 차이로 확률이 정해지므로 모든 비용에 같은 금액을 더해도 확률은 같습니다.

- τ가 작으면 비용이 낮은 충전소에 선택이 강하게 집중됩니다.
- τ가 크면 비용 차이에 덜 뚜렷하게 반응하고 A/B 선택 확률이 비슷해집니다.
- A/B 비용이 같으면 τ에 관계없이 50%씩입니다.

아래는 **한 운전자의 선택 시점에** A 종합 비용이 12,000원, B가 10,000원이라는 가정 예시입니다.

| τ | B 선택 확률 |
|---:|---:|
| 1,000원 | 약 88.1% |
| 2,000원 | 약 73.1% |
| 4,000원 | 약 62.2% |

τ는 운전자 수·추가 청구액이 아닙니다. 가격 민감도가 충전요금 항만 조절하는 반면, τ는 **가격·거리·대기를 합친 종합 비용 차이 전체**에 작용합니다. 현재는 모든 운전자에게 공통 행동계수를 적용하고 선택을 확률적으로 처리합니다. 개인별 실제 선호를 학습한 모델은 아닙니다.

행동계수를 추정할 때는 가격계수·α·β·τ의 상대적 척도를 함께 고려해야 합니다. 모든 비용계수와 τ를 같은 비율로 키우면 같은 선택 확률이 되므로 각각을 독립적으로 식별할 수 있다고 가정해서는 안 됩니다.

## 4. 수요와 충전시간 가정

### 4.1 신규 운전자 수

기본 **24명**은 앞으로 새로 오는 차량 수입니다. 시작 시 이미 충전 중인 차량은 포함하지 않습니다. 차량이 많아질수록 처리 능력에 비해 수요가 커져 대기가 발생하기 쉽습니다. 선택한 충전소의 가동 대수와 점유시간에 따라 같은 24명의 수요 압력도 달라집니다.

v1 이용률 입력은 신규 운전자 수를 바꾸지 않습니다. v2는 제공된 구간별 기대 충전 시작 건수로 A/B 원래 선택지별 포아송 차량을 생성합니다. 기대값과 생성 평균은 다를 수 있으며 실제 도착·대기·포기 차량은 관측하지 않습니다.

### 4.2 도착 생성 기간

기본 **60분** 안에서 운전자별 도착 시각을 균등분포로 생성한 뒤 도착순으로 처리합니다. 정확한 등간격 도착이 아니므로 일부 시간에 몰릴 수 있습니다.

같은 인원을 30분 안에 도착시키면 120분에 나눠 도착시키는 것보다 수요가 집중됩니다. 이 값은 전체 차량의 충전을 종료시키는 시각이 아닙니다. 기간 내 도착한 차량은 종료 시점 이후에 끝나더라도 모두 집계합니다.

### 4.3 차량당 충전량

기본 **30kWh**를 모든 신규 차량에 동일하게 적용합니다. 충전량이 커지면 차량당 요금과 충전소 간 단가 차이의 금전적 효과가 커집니다.

예를 들어 단가 차이가 50원/kWh라면 10kWh에서는 차량당 500원, 30kWh에서는 1,500원 차이입니다. 충전시간 변화 여부는 아래 모드에 따라 다릅니다.

### 4.4 신규 차량 충전시간

기본은 **출력 기반 `power`**입니다. 충전량에 맞춰 시간이 달라지도록 웹 화면과 계산 엔진의 기본값을 함께 적용합니다. `assumed`는 별도로 선택하는 비교용 가정입니다.

| 방식 | 계산 | 충전량을 바꿀 때 |
|---|---|---|
| `assumed` | 운전자별 20~40분 균등분포 | 요금은 바뀌지만 시간 범위는 유지 |
| `power` | `충전량 / 대표 출력 × 60분` | 충전량에 따라 시간도 바뀜 |

출력 모드에서 30kWh를 50kW로 충전하면 36분입니다. 동일 운전자도 선택한 충전소의 대표 출력이 다르면 충전시간이 달라질 수 있습니다.

두 방식 모두 간소화 가정입니다. 충전효율·충전곡선·출력 공유·충전 완료 후 장시간 점유는 모델링하지 않습니다. 대표 출력은 개별 충전기의 실제 순간 출력을 보장하지 않습니다.

### 4.5 초기 차량의 잔여 충전시간

현재 데이터에서 실제 잔여시간을 알 수 없으므로 다음처럼 생성합니다.

- `assumed`: 초기 충전 차량마다 0~30분 균등분포.
- `power`: 초기 충전 차량마다 0~(`충전량 / 대표 출력 × 60`)분 균등분포.

초기 충전 차량은 이 시간 동안 충전기를 점유합니다. 실측된 잔여시간이 아니며 화면에서 별도 숫자로 조절하는 항목도 아닙니다.

## 5. 거리 가정

### B 추가 거리와 산정 방식

- 좌표 방식: A/B 좌표의 직선거리를 자동 계산합니다. 추정값이며 도로 경로를 사용하지 않습니다.
- 사용자 가정값: 입력한 km를 사용합니다. 예시의 2km는 고정된 실제 도로 거리가 아닙니다.

추가 거리가 길면 `α × 거리`가 커집니다. A가 원래 목적지라는 설정에서 A 추가 거리는 0km입니다. 이동시간을 실제 충전소 도착 시각에 더하지 않으며 모든 운전자에게 같은 A/B 추가 거리 조건을 적용합니다.

민감도 분석에서 거리 수준을 변경하면 실제 충전소 좌표를 바꾸지 않고 사용자 가정 거리만 바꿉니다.

## 6. 요금 정책 설정

### 6.1 여유 판정 대기율

**대기율은 기다리는 차량 비율이 아니라 빈 충전기 비율입니다.**

```text
대기율 = 빈 충전기 / (빈 충전기 + 충전 중인 충전기)
이용률 = 충전 중인 충전기 / (빈 충전기 + 충전 중인 충전기)
```

사용 불가·미확인 충전기는 처리 능력에서 제외합니다. 기본 대기율 기준 50%에서는 다음처럼 판정합니다.

| 상태 | 조건 |
|---|---|
| 여유 | 빈 충전기 비율 50% 이상 |
| 보통 | 빈 충전기가 있지만 비율이 50% 미만 |
| 혼잡 | 가동 가능한 충전기가 모두 충전 중, 즉 이용률 100% |
| 불가·미확인 | 처리 가능한 충전기가 없는 경우 |

화면의 기준은 여유↔보통 경계를 바꿉니다. 혼잡 조건을 이용률 80% 등으로 바꾸는 설정은 현재 없습니다. 모든 충전기가 비어 있는 B는 여유 기준을 30/50/70%로 바꿔도 계속 여유일 수 있습니다.

### 6.2 할인율과 할증율

기본 여유 할인율은 **20%**, 혼잡 할증율은 **15%**입니다. 할인율·할증율이 아니라 각 충전소의 기본 단가가 실제 요금표에서 옵니다.

| 정책 | 여유 | 보통 | 혼잡 |
|---|---:|---:|---:|
| 고정요금 | 기본 × 1 | 기본 × 1 | 기본 × 1 |
| 할인·할증 | 기본 × (1−할인율) | 기본 × 1 | 기본 × (1+할증율) |
| 할인 전용 | 기본 × (1−할인율) | 기본 × 1 | 기본 × 1 |

단가는 기존 관제처럼 소수 첫째 자리로 반올림합니다. 수동/v1은 시작 상태 또는 한 시점 예측으로 단가를 고정합니다. v2는 제공된 각 구간의 이용률로 단가를 정하고 차량은 선택 시 단가를 적용합니다. 시뮬레이션에서는 관제의 시간대 배수를 적용하지 않습니다.

할인을 크게 하면 다른 조건이 같을 때 해당 충전소를 선택하기 쉬워지지만, 그곳에 대기열이 생길 수 있어 전체 대기 감소가 보장되지는 않습니다. 관제 탭의 정책 슬라이더와 시뮬레이션 입력은 독립적입니다.

## 7. 실험 설정

### 7.1 반복 횟수

기본 **100회**입니다. 반복마다 도착 시각·선택 난수·필요한 시간 가정을 생성하고 결과 평균을 냅니다. 한 반복의 세 정책은 같은 운전자 조건을 공유합니다.

반복을 늘리면 무작위 표본에 따른 평균의 흔들림을 줄일 수 있지만 잘못된 행동 가정이나 데이터 편향을 고쳐주지는 않습니다. 결과의 표준오차는 반복 간 변동이며 실제 미래 예측오차가 아닙니다.

### 7.2 난수 시드

기본 **42**는 재현성을 위한 번호이며 값 자체에 현실적 의미는 없습니다. 같은 충전소 데이터·예측·설정·시드에서는 같은 결과가 나옵니다. 실제 데이터나 외부 예측이 달라졌다면 시드만 같다고 같은 실험은 아닙니다.

## 8. 외부 AI 예측을 사용할 때

`요금·수요 기준`에서 v1 또는 v2를 선택하면 A/B의 같은 종류 예측으로 상태를 판정합니다. 예측 이용률이 `u`라면 예상 빈 충전기 비율은 `1-u`입니다. v2 원클릭 연결·시간 정렬·생성 방식은 [실제 모델 연결 설명](simulation-report.md#실제-제공-모델-연결)을 참고하세요.

기본 기준에서 예측 이용률 20%는 여유, 80%는 보통, 100%는 혼잡입니다. v1은 정책 단가에만 반영합니다. v2는 구간별 이용률과 제공된 시작 건수 추정으로 차량을 생성하고 선택 시 단가를 적용합니다. 초기 점유는 수집 상태입니다. 충전량·행동계수·미래 대기열을 이용률에서 만들어내지 않습니다.

외부 모델 예측의 ID·급속/완속·값 범위·생성/대상 시각을 검증합니다. 형식 검증을 통과했다고 모델 정확도까지 검증한 것은 아닙니다. 예측 대상 시각은 실행 시점보다 미래여야 합니다.

## 9. 결과 해석과 근거 보강

- 가상 선택과 대기는 실제 분산 실적이나 배전망 피크 저감 성과가 아닙니다.
- 총 할인액은 이용자 혜택 합계이며 사업자 순손실과 다릅니다. 수입 차이는 비용을 반영하지 않은 단순 충전 매출 비교입니다.
- 선택 당시 예상 대기와 실제 대기를 구분해 계산하지만, 정보가 정확하고 취소·이탈이 없는 현재 모델에서는 일치합니다.
- 대기열은 도착순으로 충전기에 배정하며 취소·포기·예약·다른 충전소로 재이동은 없습니다.
- 민감도 분석은 한 항목씩 바꾸는 비교입니다. 여러 항목의 상호작용이나 실제 정확성을 검증하는 기능은 아닙니다.
- 수요·충전 특성은 실제 이력의 통계·분포로, 행동계수는 실제 선택 기록 또는 선택 실험 설문으로 보강할 수 있습니다. 자료가 없으면 가정값과 출처·범위를 명시합니다.
- 강화학습은 요금 정책을 선택하는 용도로 검토할 수 있지만, 시뮬레이션 성과가 커지도록 행동계수를 고르는 것이 실측 보정은 아닙니다.

보고서에는 충전소 ID·수집 시각·외부 예측 정보·입력값·시드·비교 범위·모델 가정을 함께 남기세요. 사이트의 일반 결과 및 민감도 CSV에 근거표와 조건을 함께 저장할 수 있습니다.

## 10 충전 부하 리포트

일반 실행 후 A/B 및 합산 15분 평균 등가 부하, 반복별 피크 평균, 고정요금 대비 저감률, 도착 기간 이후 충전량을 확인할 수 있습니다. 단일 HTML 리포트와 시계열 CSV 다운로드를 지원합니다. 민감도 분석에서도 수준별 피크를 비교합니다.

부하는 충전량과 모의 충전시간으로 계산합니다. 20~40분 가정에서 대표 출력 초과가 발생할 수 있어 리포트에 표시하며, 물리적 부하 해석에는 출력 기반 충전시간 모드를 권장합니다. 초기 차량의 잔여 에너지는 대표 출력과 가정 잔여시간으로 추정합니다. 실제 배전망 저감 실적은 아닙니다. 상세 계산과 모델 출력 예시는 [AI 출력 계약과 부하 리포트](simulation-report.md)를 참고하세요.
